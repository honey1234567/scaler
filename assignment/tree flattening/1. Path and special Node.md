# Approach

Below is a **clean solution using Tree Flattening (Euler Tour / DFS time-in–time-out)**.

---

## Problem Restatement

* Tree with **N nodes (1…N)**
* A **special node A**
* Edges given in `B` (size `N-1 × 2`)
* For each query `(X, V)`:

  * Output **1** if node `X` lies on the **path from A to V**
  * Else output **0**

---

## Key Insight

In a tree:

> Node **X** lies on the path from **A → V**
> **iff**
> **X is an ancestor of V in a tree rooted at A**

So the problem reduces to **ancestor queries**.

---

## Tree Flattening (Euler Tour)

We root the tree at **A** and perform a DFS.

For every node `u`, record:

* `tin[u]` → time when DFS enters `u`
* `tout[u]` → time when DFS exits `u`

### Property

For nodes `X` and `V`:

```
X is ancestor of V
⇔ tin[X] ≤ tin[V] AND tout[V] ≤ tout[X]
```

This lets us answer each query in **O(1)**.

---

## Algorithm

### Step 1: Build adjacency list

```python
adj = [[] for _ in range(N+1)]
for u, v in B:
    adj[u].append(v)
    adj[v].append(u)
```

---

### Step 2: DFS from root A (Tree Flattening)

```python
time = 0
tin = [0] * (N+1)
tout = [0] * (N+1)

def dfs(u, parent):
    global time
    time += 1
    tin[u] = time
    for v in adj[u]:
        if v != parent:
            dfs(v, u)
    tout[u] = time
```

Call:

```python
dfs(A, -1)
```

---

### Step 3: Answer Queries

For each query `(X, V)`:

```python
if tin[X] <= tin[V] and tout[V] <= tout[X]:
    print(1)
else:
    print(0)
```

---

## Time & Space Complexity

| Operation  | Complexity   |
| ---------- | ------------ |
| DFS        | **O(N)**     |
| Each query | **O(1)**     |
| Total      | **O(N + Q)** |
| Space      | **O(N)**     |

---

## Example

Tree:

```
    A
   / \
  2   3
     / \
    4   5
```

Query `(X=3, V=5)` → **1**
Query `(X=2, V=5)` → **0**

---

## Why Tree Flattening Works

Flattening converts hierarchical ancestor checks into **range comparisons** using entry/exit times — perfect for fast queries.

## Short Answer

We **root the tree at A** because the query asks:

> “Is X on the path from **A to V**?”

When the tree is rooted at **A**,
that path becomes **exactly the ancestor chain of V**,
so the problem turns into a simple **ancestor check**.

---

## What Goes Wrong Without Rooting at A?

A tree is **undirected** by default — there is **no parent/child direction**.

Example:

```
1 - 2 - 3 - 4
```

If A = 2, and V = 4, the path is:

```
2 → 3 → 4
```

If we root the tree at **1** instead:

```
1
|
2
|
3
|
4
```

Now:

* 2 is ancestor of 4 ✔
* 3 is ancestor of 4 ✔

But the **path from A (2) to V (4)** is only:

```
2 → 3 → 4
```

Rooting at the wrong node introduces **extra ancestors that don’t belong to the A→V path**.

---

## Why Rooting at A Fixes This

When we root at **A**:

* Every node has a **unique path from A**
* The path **A → V** is exactly the **ancestor chain of V**
* So:

  ```
  X is on path (A, V)
  ⇔ X is ancestor of V (rooted at A)
  ```

This makes the condition **correct and sufficient**.

---

## How Euler Tour Depends on Rooting

Euler Tour gives us:

* `tin[u]`, `tout[u]`
* Valid ancestor check only works **with respect to the chosen root**

Ancestor condition:

```
tin[X] ≤ tin[V] ≤ tout[X]
```

This statement is **only meaningful relative to the root**.

---

## Visual Intuition

Root at A:

```
A
|
X
|
V
```

✔ X is ancestor → on path

Root elsewhere:

```
R
|
A
|
X
|
V
```

✘ R becomes ancestor of V but **not on path A→V**

---

## Summary

| Concept      | Reason                                |
| ------------ | ------------------------------------- |
| Root at A    | Defines direction from A to all nodes |
| Path (A → V) | Becomes ancestor chain                |
| Query        | Reduces to ancestor check             |
| Euler Tour   | Works correctly                       |

---

### Final Takeaway

> **We root the tree at A because only then does “ancestor of V” mean “on the path from A to V”.**

This is what makes the solution **correct and O(1) per query**.

# solution

public class Solution {
    final int maxN = (int)1e5 + 5;
    ArrayList < ArrayList < Integer > > adj;
    int[] in = new int[maxN];
    int[] out = new int[maxN];
    int timer;
     void init(){
        adj = new ArrayList < ArrayList < Integer > > (maxN);
        for (int i = 0; i < maxN; i++) {
            adj.add(new ArrayList < Integer > ());
        }
        Arrays.fill(in, 0);
        Arrays.fill(out, 0);
        timer = 0;
    }
    void dfs(int u, int par){
        in[u] = timer++;
        for(int i = 0 ; i < adj.get(u).size() ; i++){
            int v = adj.get(u).get(i);
            if(v != par){
                dfs(v, u);
            }
        }
        out[u] = timer++;
    }
    public int[] solve(int A, int[][] B, int[][] C) {
        init();
        for(int i = 0 ; i < B.length ; i++){
            int u = B[i][0];
            int v = B[i][1];
            adj.get(u).add(v);
            adj.get(v).add(u);
        }
        dfs(A, -1);
        
        int[] ans = new int[C.length];
        for(int i = 0 ; i < C.length ; i++){
            int x = C[i][0];
            int v = C[i][1];
            if(in[v] >= in[x] && out[v] <= out[x]){
                ans[i] = 1;
            }
            else{
                ans[i] = 0;
            }
        }
        return ans;
    }
}
